# The Dog Ate My Homework: Funniest Excuse

[![make.fun bounty](https://make.fun/badge-bounty.svg)](https://make.fun)
[![license: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

One line, under 200 characters, in which a dog explains why the
homework got eaten — entered in the make.fun bounty
"The Dog Ate My Homework: Funniest Excuse".

## The line

> You said 'the dog ate my homework' was the oldest excuse in the book, so I ate the book too.

92 characters. The teacher called "the dog ate my homework" the
oldest excuse in the book, so the dog ate the book too — a
meta-twist on the cliche itself, in a dog's voice, with no human
shame. It stands alone and uses none of the saturated field
patterns ("show your work", "graded it, it failed", "filed it in
my stomach").

## Run

```sh
python3 main.py   # writes /output/entry.txt
```

Deterministic: two runs produce byte-identical output. Standard
library only, no network, no subprocess, no eval.
